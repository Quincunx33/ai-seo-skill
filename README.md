A compact SEO skill package for technical audits, structured data review, page experience checks, and safe implementation guidance.

## Overview

This repository contains a practical SEO workflow focused on:

- technical SEO analysis
- crawlability and indexability
- canonical, sitemap, and metadata checks
- on-page content quality
- performance and UX awareness
- safe, evidence-based implementation

## Included Files

- `SKILL.md` — complete SEO operating contract and workflow
- `references/` — bundled SEO playbooks and guidance
- `scripts/seo_smoke_check.py` — lightweight URL smoke test
- `universal-seo-engineer-pro-v2.skill` — original packaged skill file
